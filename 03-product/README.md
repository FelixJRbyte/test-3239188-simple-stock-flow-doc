menciona `spec.md` como «qué y por qué», pero **no se entrega** — ver nota
del README del reto). Todo lo que sigue se deriva de las decisiones de diseño
del modelo (DP-02, DP-03, D-05…) y se marca como **[derivado]** donde el
modelo no lo dice explícitamente.
